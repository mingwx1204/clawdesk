# ClawDesk — AI 桌面助手

> **当前版本：v0.5.2**（2026-08-10）

基于 **Tauri 2 + Vue 3 + Rust** 的 Windows 桌面智能体：集成 **微信 Bot**、**多模型路由**（主对话 / 识图 / 生图）、**Agent 工具链**、**定时任务**、**本地记忆** 于一体，本地优先，数据全部保存在本机。

---

| 模块 | 说明 |
|---|---|
| 💬 主对话 | AI 聊天、流式输出、思考链、图片附件、多会话管理 |
| 📱 微信 Bot | 最多接入 **10 个微信**，扫码登录、自动回复、主动聊天、人设 |
| 🤖 智能 Agent | ReAct 工具循环、规划、逐步确认、断点续跑 |

## 📦 安装与启动

### 方式一：正式版（推荐）
直接运行 `clawdesk.exe`（安装版位于 `C:\ClawDesk\`），双击桌面快捷方式启动。

### 方式二：开发模式
```powershell
# 需要 Node.js 18+ 与 Rust 工具链
cd ClawDesk
npm install
.\start-dev.ps1        # 一键启动（自动编译 Rust + 前端，日志写到 D:\clawdesk_dev.log）
```

### 构建正式版
```powershell
npm run tauri build    # 生成独立可执行文件（前端资源内嵌，无需服务器）
```

## 📱 微信 Bot（核心特色）

### 接入
1. 打开微信面板（顶部工具栏 🐧 按钮）
2. 点击「获取二维码」→ 手机微信扫码
3. 扫码确认后自动登录，**软件重启后自动续连**（凭据 DPAPI 加密保存）

### 多账号
- 支持 **10 个微信槽位**，各自独立：登录、人设、聊天记录、AI 会话记忆
- 顶部切换槽位，上次选中的槽位自动记忆

### 自动回复
- 收到消息 → AI 自动回复（默认开启，面板可关）
- **人设**：每个微信独立人设（存 `persona.md`），AI 按人设说话
- **记忆共享**：自动回复与主动聊天共用同一份会话记忆，不"人格分裂"

### 主动聊天（拟人化）
- 随机间隔触发（**1~180 分钟可调**），AI 主动找用户聊天
- **拟人机制**（参考 MaiBot 设计）：
  - 🤫 **静默机制**：AI 发过消息、用户没回 → 保持安静，等用户先开口
  - 🧠 **AI 自主决策**：生成前 AI 自评"现在值得打扰吗"，不值得就不发
  - ⏳ **空闲退避**：用户持续不回 → 间隔指数拉长（封顶 60 分钟），回复后立即恢复
  - 🚫 **存在感惩罚**：AI 发言占比过高时自动闭嘴
  - 🌙 **深夜不打扰**：23:00~08:00 不主动
- **像真人说话**：默认 5~40 字短句、口语化；**只有用户明确要求字数才写长文**

### 媒体处理
| 类型 | 处理方式 |
|---|---|
| 图片 | 按文件头识别真实格式（JPEG/PNG/GIF/WEBP/BMP）→ 视觉模型识图 |
| PDF | `file_read` 自动提取文本（纯 Rust 解析） |
| ZIP 压缩包 | **≤2MB 自动解压**查看内容；超过 2MB 明确告知不支持 |
| 语音/视频 | 下载保存到本地附件目录 |
| 文本文件 | 直接读取内容（限制 1MB） |

- 聊天记录保存在 `D:\ClawDeskData\wechat\slot{N}\history.jsonl`

## 🤖 智能 Agent

- **ReAct 工具循环**：AI 自主规划 → 调用工具 → 观察结果 → 继续，直到完成
- **权限模式**：`关闭`（直通模型）/ `计划只读` / `逐步确认`（高危操作先弹窗）/ `YOLO 全自动`
- **工具循环上限**：单轮最多调用工具次数（设置可调，**推荐 5~15，范围 1~30**），防死循环
- **断点续跑**：任务中断后从断点恢复
- **进度事件**：实时显示当前轮次、思考、工具调用

### 内置工具（部分）
文件读写 / 目录列表 / 图片识别（`analyze_image`）/ OCR / 生成图片 / 浏览器自动化 / 知识库检索 / 记忆搜索 / MCP 工具 / 终端命令（沙箱内）

## 🧠 记忆与安全

- **会话持久化**：SQLite 存储，重启不丢
- **上下文压缩**：超阈值自动摘要压缩（阈值可调）
- **知识库 RAG**：本地文本向量检索
- **快照回滚**：文件修改前自动备份，可对比/回滚
- **敏感文件保护**：拦截 .env / 密钥 / 凭据等敏感路径
- **沙箱目录**：只允许 AI 访问授权目录
